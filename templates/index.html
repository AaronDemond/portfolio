Hello

I’m a recent Computer Science graduate and open-source software developer with a strong interest in building reliable, efficient systems and solving technical problems from the ground up. My experience spans Java, C++, Python, SQL, Linux, Windows, backend systems, testing, automation, AI and agentic coding workflows, and working with established software platforms and APIs.
My current work is centered around simulation software designed to prove the resilience of a fault-tolerant, secure telemetry platform similar to what government agencies might use when conducting coordinated missions in the field. It is built with C++ on the backend and Python for simulation. It incorporates a web-based interface, a PostgreSQL database, NATS JetStream, Protocol Buffers (Protobuf), and a modular architecture.
